### 💫 About Me

Hey there! I'm **Pratyush K Nayak**, a software engineer and builder based in India. I love crafting high-performance web applications, browser extensions, and mobile tools with polished, intuitive user interfaces.

- 🎬 **Featured Release:** Creator of **[UltraWide Video Fill Pro](https://github.com/pratyushkk/ultrawide-video-fill-pro)** — a GPU-accelerated extension for 21:9 & 32:9 displays, live on the **[Microsoft Edge Add-ons Store](https://microsoftedge.microsoft.com/addons/detail/ultrawide-video-fill-pro/kllbjjefnjodgoaglaghcakajfbjmpnm)**.
- 📱 **Mobile & Systems:** Maintainer of **[NetSwiss](https://github.com/pratyushkk/Netswiss-app)**, an Android network diagnostic toolkit with Mock GPS, real-time speed monitoring, and a per-app firewall via `VpnService`.
- ✍️ **Writing:** Sharing insights, tutorials, and engineering deep-dives on **[Hashnode](https://pratyushkk.hashnode.dev/)**.
- ⚡ **Passions:** Web performance, custom shader pipelines (WebGPU / WebGL2), Manifest V3 architecture, and sleek design systems.
